How it works

Enrollment

One-time signup with the Aadhaar-linked NREGA ID.

Check-in

Same biometric/geo check-in as today — nothing changes.

Continuous pinging

Nearby phones (or ₹150–300 BLE tags) exchange random pings all shift.

Local aggregation

Each phone stores peer confirmations offline until signal appears.

Presence scoring

Backend rebuilds each worker’s presence timeline for the day.

Flag & review

Unexplained gaps go to the block officer before wages are released.
